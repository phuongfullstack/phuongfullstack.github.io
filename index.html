01 — About

Backend depth, full-stack reach

Duy Tan University · B.Eng. Software Engineering

I build the parts of a product that have to keep working: APIs, domain logic, data models, integrations and the pipelines that put them in production. Most of that has been in the .NET ecosystem — .NET Core and .NET Framework, ASP.NET Web API, Entity Framework — paired with whichever front end the product needs.

Along the way I've re-platformed a gaming kiosk module onto modern .NET, engineered portfolio and transaction modules for a fintech platform, integrated Stripe, Apple and Google billing for a consumer subscription product, and led a small team building an AI image-generation widget end to end.

I care about the unglamorous things — readable code, tests that mean something, infrastructure described in Terraform instead of clicked into a console, and pull requests that leave the reviewer better informed. I review a lot of code and mentor where I can.

  • Architecture microservices, serverless, containerised workloads, event-driven integration
  • Delivery Agile/Scrum, CI/CD with GitHub Actions & Azure DevOps, IaC with Terraform
  • Quality xUnit, NUnit, Moq, Jest, Jasmine, code review, Codacy & Codecov gates
  • Team mentoring, leading small teams, writing the docs nobody else writes
